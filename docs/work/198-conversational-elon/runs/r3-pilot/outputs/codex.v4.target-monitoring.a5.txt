You’re trying to detect missed successful runs. I recommend one hosted heartbeat monitor, independent of `edna` and your home network.

- Configure it to expect a daily success signal after the 03:00 run, with a deadline allowing for the job’s normal runtime and the correct timezone.
- Have the cron command send that signal **only when the Python script exits successfully**. Ensure failures return a nonzero exit code.
- Have the monitor email you when the signal misses its deadline. That covers startup crashes, missed cron runs, and `edna` being offline.
- Test a deliberate failure and confirm the alert arrives.

Keep the existing summary email. Central logs could help investigate a failure, but they don’t solve unnoticed failures by themselves.
