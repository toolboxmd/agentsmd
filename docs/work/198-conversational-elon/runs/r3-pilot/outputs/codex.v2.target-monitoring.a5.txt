**Requirements and who asked:** You want to know when `nightly-sync` fails without reading logs.
**Deleted:** Central logging and Docker are unnecessary for this one job.
**Bottleneck:** The script sends email only after finishing, so a startup crash leaves you unaware.
**Checked myself:** From what you told me, cron runs it at 03:00 on `edna`; an expired token caused four startup failures, and no independent alert exists.

You want failed or missed syncs to alert you automatically. I recommend one external dead-man’s-switch monitor: the script sends it a success ping only after completing, and the monitor emails you if that ping misses the daily deadline, including when `edna` is offline.

Set that deadline to 03:00 plus the job’s normal runtime and a reasonable buffer, then deliberately skip a ping to verify the alert reaches you. The Synology does not need to run anything for this.
