You want a notice when nightly-sync dies, even if it crashes before the summary email. Set up one Healthchecks.io check on a daily cron schedule with about an hour of grace, and curl its ping URL from a wrapper only when the script exits 0, so a missing ping after 03:00 emails you if startup throws, cron does not run, or the Mac is off. Renew the expired token or that email arrives every morning, and leave the Synology log stack alone: it would have had nothing to store on these crashes, and you will not read it.
