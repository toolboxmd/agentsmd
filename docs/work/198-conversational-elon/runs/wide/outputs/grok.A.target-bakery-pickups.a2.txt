**Today, before the partner arrives**

Leave next-month cakes on a planning view and start them only after today's view is empty. Run the rest of this week that way so the partner sees a working rule, not a blank requirements doc.

**Next week with the partner, in this order**

1. **Counter queue first.** Put prepaid cake orders in Sales with customer, cake, pickup date and time, and preparation status. The counter's default screen is cakes due today and any overdue cakes still unmade, sorted by pickup time. Future orders live on a separate planning screen. 2. **Manufacturing second, cakes only.** Each prepaid cake becomes a production order scheduled on the pickup date, using the date the customer will collect it. Marking that order done updates the preparation status on the counter. Limit this to custom cakes for the first cycle.
