You want a timely nudge to decide on each renewal. I recommend using the phone calendar you already check, with no agents or workflows:

1. When the statement arrives, add one all-day event per contract dated 14 days before its notice deadline. Title it like "Decide: home insurance renewal" and put the renewal date and notice deadline in the notes.
2. Set an alert on each event. Add a second alert on the deadline itself if you want a backstop.
3. Add one yearly event for the week the statement usually arrives: "Enter renewal reminders."

That takes about ten minutes a year and costs nothing, so you can keep that budget.
