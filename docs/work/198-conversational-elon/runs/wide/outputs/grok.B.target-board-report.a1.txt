You want a monthly board report of net sales by region that rebuilds from the accounting export without hand sums. This week, add one local rollup on the workbook you already have: group by region and month and sum the signed net amount, refunds included, using Excel Power Query or a short script you rerun on each new export. Airbyte, Snowflake, dbt, and Power BI belong later, when a second source arrives or the file no longer fits on one machine; the report this week is one table that already fits on your computer.
