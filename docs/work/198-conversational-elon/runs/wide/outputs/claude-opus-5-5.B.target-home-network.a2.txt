You want dependable calls at that desk, and the evidence points at the desk link, not the network. Other devices on the same router stay connected during drops, so a new gateway, managed switches and Grafana would likely leave the problem in place. Swap the old cable that runs through the tight grommet for a new one (route it with a gentler bend), and if drops continue, try a different router port and check the computer's Ethernet link for flapping.

The UniFi setup is fine as a separate future-proofing project, but I'd only start it after the cable test.
