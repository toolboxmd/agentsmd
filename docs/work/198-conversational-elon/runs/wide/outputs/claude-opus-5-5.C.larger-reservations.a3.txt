You're trying to stop an item ever being booked twice for overlapping dates, without replacing your workflow this week.

I don't recommend the colours plan, because it can't meet the owner's rule. My recommendation is to keep the spreadsheet as the record and make one booking form the only way to add a reservation. The form's save step would take a lock, check the item's existing dates, and then either append the booking or reject it with the conflicting booking shown. The sheet itself would be locked against direct edits. In Google Sheets this is a small Apps Script web app using `LockService`, so there's no new server or database to run, and it's realistic for this week.
