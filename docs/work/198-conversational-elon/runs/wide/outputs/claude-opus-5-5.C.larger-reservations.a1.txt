You're trying to make it impossible to save two overlapping bookings for the same item. Colours can't do that, and I don't know of any spreadsheet check that holds when two people save at the same instant.

I recommend one small Postgres table for bookings with an exclusion constraint on item identifier and date range. The database then refuses the second of two overlapping saves, even if both arrive together, and agents see an error instead of a silent clash. The table and constraint are a few hours of work, so this fits in the week. The spreadsheet can stay as a read-only view.
