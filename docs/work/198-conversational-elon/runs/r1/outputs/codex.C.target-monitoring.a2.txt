**Requirements and who asked:** You asked for failures to stop going unnoticed, including crashes before the summary email.
**Deleted:** Central logging and moving everything into Docker add work without guaranteeing an alert.
**Bottleneck:** The job itself sends the only notification, so a startup crash silences it.
**Checked myself:** From the facts you supplied, four startup failures produced no email; I haven’t inspected the setup.

I recommend a hosted heartbeat monitor for this one job. Keep cron and Python on `edna`; have an independent service expect a daily success signal and email you when it doesn’t arrive.

- Wrap the Python command so it reports startup, success, and failure. A nonzero exit should trigger an immediate alert.
- Set a completion deadline after 03:00, allowing for the job’s normal runtime. Missing that deadline alerts even if cron never runs, the Mac is off, or the wrapper fails.
- Test both a deliberate script failure and a missing run, and verify that the alerts reach you.

Keep the existing summary email. The Synology can collect logs later if troubleshooting warrants it, but it shares your home’s power and internet connection, making it a weaker home for the only watchdog.
