`git fetch` downloads commits/branches from the remote into your local repo but doesn't touch your working branch — it just updates things like `origin/main` so you can look before you leap. `git pull` does that fetch and then immediately merges (or rebases, if configured) the remote changes into your current branch. So `pull` = `fetch` + `merge`. If you want to review incoming changes before integrating them, use `fetch` then `git diff main origin/main` (or similar) before merging manually.
