You want a heads-up when nightly sync dies, even if it crashes before its own summary email. A central log on the Synology still waits for you to open it, which is how four quiet nights already slipped past. Use a shell wrapper in cron that always writes one status file to a NAS share (ok, or the traceback), and a DSM scheduled task at 04:00 that emails you only when that file is missing or failed.
