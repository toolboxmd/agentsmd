`git fetch` downloads new commits and branches from the remote and updates your remote-tracking refs (like `origin/main`), but leaves your local branch and working tree untouched. `git pull` is `git fetch` followed by integrating those changes into your current branch, by merge by default or rebase if you use `--rebase` or set `pull.rebase`. Use `fetch` when you want to inspect incoming changes first (for example `git log HEAD..origin/main`), and `pull` when you just want to update.
