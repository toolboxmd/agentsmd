You want a message on the night the sync fails.

Put the failure mail in a shell wrapper that cron runs, and send it through the same mail path as the success summary. The wrapper runs the Python script, and on any non-zero exit it emails you the traceback. A crash during startup then lands in your inbox.

```cron
0 3 * * * /path/to/run-nightly-sync.sh
```

```sh
#!/bin/sh
/path/to/python /path/to/nightly-sync.py >/tmp/nightly-sync.log 2>&1
status=$?
if [ "$status" -ne 0 ]; then
  # email /tmp/nightly-sync.log with the mail path the summary already uses
fi
exit "$status"
```

The Synology stays out of this. A log collector there would be another system to keep alive, and it would still wait for you to look.
