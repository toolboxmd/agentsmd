`git fetch` downloads new commits and branches from the remote and updates your remote-tracking refs (like `origin/main`), but leaves your local branch and working tree untouched. `git pull` is `git fetch` followed by integrating those changes into your current branch, via a merge by default or a rebase if you use `--rebase` or set `pull.rebase`. Use `fetch` when you want to look first (for example `git log HEAD..origin/main`), and `pull` when you just want to be up to date.
