I’d use the existing Excel workbook with a simple lookup sheet. For 240 parts, one laptop and read-only lookups, Retool/Supabase or Next.js would add hosting, maintenance and another copy of data to keep in sync without improving the counter workflow.

I’d put it together like this:

- Keep your parts list as the authoritative data and format it as an Excel Table.
- Add a **Counter Lookup** sheet with one clearly marked cell for entering the part code.
- Use `XLOOKUP` with an exact match to show the **shelf location** and **selling price** in large text.
- Show “Code not found” for an unknown code and leave results blank until a code is entered.
- Store codes as text so leading zeros are preserved, and protect the formula cells against accidental edits.

Your routine becomes: type the code from the slip, press Enter, read the shelf and price. Changes you make to the parts table appear immediately in the lookup.

I’d consider a separate app when you need access from other devices or start recording stock movements or sales. For the workflow you have today, Excel is the simplest fit.
