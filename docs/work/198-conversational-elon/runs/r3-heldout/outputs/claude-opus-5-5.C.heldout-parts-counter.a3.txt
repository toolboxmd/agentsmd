You want to look up a part in seconds without changing how you keep the list. Add a lookup box to the workbook you already have.

1. Add a sheet called `Lookup`.
2. In `A1` type `Code`. You'll type part codes into `B1`.
3. In `A2` paste this formula (assuming your parts sheet is `Parts` with codes in column A, location in B and price in C; change the names and letters to match yours):
   ```
   =XLOOKUP(TRIM(B1),Parts!A:A,Parts!B:C,"Not found")
   ```
   The location shows in `A2` and the price in `B2`.
4. Make `B1` large and bold, and save with the `Lookup` sheet active so it opens there.

At the counter you click `B1`, type the code and press Enter. Any change you make to the parts sheet shows up immediately because the formula reads it directly. If you see `#NAME?`, your Excel is older than XLOOKUP. In that case put `=VLOOKUP(TRIM(B1),Parts!A:C,2,FALSE)` in `A2` for the location and the same formula ending in `3,FALSE` in `B2` for the price.
