You want to type a code and get its location and price immediately. The smallest fix is a lookup box inside the workbook you already have.

1. Add a sheet named `Lookup` and keep it as the first tab.
2. In `A1` type `Part code`, and leave `B1` empty for typing codes.
3. In `B2` enter:
   `=XLOOKUP(B1, Parts!A:A, Parts!B:B, "Not found")`
4. In `B3` enter:
   `=XLOOKUP(B1, Parts!A:A, Parts!C:C, "Not found")`
5. Change `Parts` and the columns to match your sheet name and layout. The formulas assume codes in A, shelf in B, and price in C.

At the counter, click `B1`, type the code, and press Enter. Edits you make to the parts list show up right away because the formulas read it directly.
