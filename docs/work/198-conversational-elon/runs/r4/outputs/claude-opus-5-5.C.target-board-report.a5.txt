You want an accurate monthly regional net sales table for the board without the manual summing. I recommend an Excel PivotTable on the export table. You can set it up today:

1. Format the export as an Excel Table (Ctrl+T) so new rows are picked up automatically.
2. Insert a PivotTable from that table, with region as Rows, the date grouped by Month (and Year) as Columns, and Sum of net amount as Values. Refunds net out automatically because they are already negative.
3. Each month, paste the new export into the same table and click Data > Refresh All.
4. Check once that the pivot's grand total equals the sum of the export's amount column.
