I recommend against shipping the initials column and naming convention for this delivery. It does not meet the contract: typed initials do not prove approver identity, there is no reliable approval time, anyone with edit access can change or overwrite the content so the exact approved version is not retained for seven years, and nothing stops an author approving their own document. With 12 remote authors able to edit the shared folder, we need a separate immutable approved store with authenticated approval record before delivery.
