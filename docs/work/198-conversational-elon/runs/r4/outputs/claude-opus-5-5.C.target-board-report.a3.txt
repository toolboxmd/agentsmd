You want the board numbers produced reliably without manual summing. I recommend a PivotTable in the same workbook, and you can set it up today rather than this week:

1. Click inside the export table and choose Insert > PivotTable.
2. Put Region in Rows and Date in Columns, then group Date by Months and Years.
3. Put net amount in Values as Sum. Refunds net out automatically because they are already negative.
4. Each month, paste the new export into the same table and press Data > Refresh All.
