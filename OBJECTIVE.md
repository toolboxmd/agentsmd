# Objective

A reliable out-of-the-box system that turns confirmed direction into shipped,
verified work, with humans only for judgment or authority. Done when:

- After setup, a fresh agent loads current direction, flags stale truth, and
  starts useful work without manual routing.
- Ordinary work is one loop: Issue, smallest workflow, proof, reviewed PR, and
  authorized merge, release, install, and verification.
- Complex work runs from shaping to code unprompted; the agent grills on its
  own when taste, consequential architecture, or another user-owned call is
  unresolved.
- Humans approve only direction, taste, consequential architecture, and
  protected external impact.
- Deterministic tests prove contracts, packaging, install, and regressions.
- The release installs cleanly and the user Live Verifies it in real work;
  failures become fixes and regressions.
