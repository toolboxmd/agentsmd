# Objective

Make AgentsMD a reliable out-of-the-box development system that turns
confirmed Project Direction into shipped, verified solutions with human
involvement only where judgment or authority is genuinely required.

The Objective is complete when:

- After one-time installation and configuration, a fresh supported agent and
  repository load current Project Direction, detect missing or stale project
  truth, and begin useful work without manual workflow routing.
- For ordinary work, the agent creates or reuses the correct GitHub Issue,
  chooses the smallest suitable workflow, implements the solution, proves it,
  opens and reviews the PR, and completes authorized merge, release,
  distribution, installation, and verification steps as one continuous
  delivery loop.
- For complex work, the agent continues through shaping, specification,
  tickets, and implementation without asking the human to select each logical
  next step. It invokes grilling only when product taste, consequential
  architecture, or another genuinely user-owned decision remains unresolved.
- Human approval is reserved for confirming or changing Vision, Mission, and
  Objective; subjective product and taste decisions; consequential or
  difficult-to-reverse architecture; and protected external impact involving
  credentials, customer data, money, destructive production changes, or
  authority not already granted.
- Routine Issue, branch, commit, test, PR, review, versioning, and delivery
  operations do not require repeated approval when repository policy or the
  current request already grants the required authority.
- Deterministic tests prove contracts, packaging, installation, and known
  regressions without requiring synthetic model-run project scenarios.
- The exact versioned artifact is released through its supported distribution
  path, installs successfully in a clean supported environment, and is
  behaviorally Live Verified by the user through ordinary work on real
  projects. Observed failures become tracked fixes and deterministic
  regressions where practical.
